# vim-keys

A Claude Code pane with a beginner cheat sheet for Neovim + NvChad v2.5 (leader = Space).

- `/vim` opens or closes the "Vim / NvChad keys" pane
- `/vim <word>` shows only the lines with that word, e.g. `/vim buffer`

Sections: modes and saving, moving, editing, search, files (NvChad), windows, terminal and help. About 40 columns wide.

## Install

```
/plugin install vim-keys --marketplace AliakbarNateghi/cc-vim-keys
```

Answer `y` to add the marketplace, then pick a scope.
